# MediaVault

Простое приложение для Pop!_OS: вставляете ссылку, выбираете качество — и ролик
или аудио сохраняется в вашу папку. Под капотом — [yt-dlp](https://github.com/yt-dlp/yt-dlp) и ffmpeg.

Задумано как личный офлайн-архив: свой контент, материалы с открытыми
лицензиями, подкасты. Скачивайте только то, что вам можно скачивать.

## Возможности

- Вставил ссылку → название, канал, длительность и обложка подгружаются в фоне.
- Выбор качества только из реально доступных: 1080p / 720p / 480p / 360p
  или MP3 (320 / 192 / 128 kbps). Если ролик только в 4K — будет «Максимум».
- Очередь: прогресс, скорость, оставшееся время, пауза, продолжение, отмена, повтор.
- Папка запоминается. Настройки: папка, формат по умолчанию, автозапуск, тема.
- yt-dlp сам обновляется в фоне при запуске, плюс кнопка «Обновить сейчас» в настройках.
- Всё локально, без сервера.

## Установка (Pop!_OS 24.04)

```bash
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 ffmpeg python3-venv python3-pip

# venv с доступом к системному PyGObject
python3 -m venv --system-site-packages .venv
source .venv/bin/activate
pip install -r requirements.txt

python3 -m mediavault
```

Нужно: Python 3.11+, GTK 4.8+, libadwaita 1.3+ (в 24.04 всё это есть).
На Pop!_OS 22.04 libadwaita слишком старая.

Запускать именно как `python3 -m mediavault` из папки проекта, а не
`python3 mediavault/main.py`: внутри пакета есть файл `queue.py`, и при прямом
запуске он перекроет стандартный модуль `queue` и всё сломает.

## Как работают пауза и отмена

yt-dlp не умеет «замораживать» загрузку. Поэтому пауза останавливает её, а
недокачанный файл (`.part`) остаётся на диске. «Продолжить» запускает загрузку
заново, и yt-dlp докачивает с того же места. Отмена удаляет недокачанные файлы.

## Обновление yt-dlp

Свежая версия ставится через pip **в личную папку приложения**
(`~/.local/share/mediavault/ytdlp-lib`), без sudo и без вмешательства в систему.
Проверка при запуске идёт не чаще раза в 12 часов. Новая версия начинает
работать после перезапуска приложения.

## Приватность

- На диск пишутся только настройки (`~/.config/mediavault/settings.json`).
- Ссылки и история загрузок нигде не сохраняются. Очередь живёт в памяти и
  пропадает при выходе.
- yt-dlp запущен в тихом режиме, свои логи на диск не пишет.
- Сеть используется только для самих загрузок, обложки и обновления yt-dlp с PyPI.

## Структура

| Файл | Что внутри |
|---|---|
| `downloader.py` | yt-dlp: метаданные, пресеты, фоновая загрузка |
| `queue.py` | очередь и состояния загрузок |
| `window.py` | главное окно и стили |
| `settings.py` | настройки и окно AdwPreferencesWindow |
| `updater.py` | обновление yt-dlp |
| `main.py` | точка входа |

## Ограничения

- Плейлисты и прямые трансляции пока не поддерживаются (только одиночные ролики).
- Видео с DRM не скачиваются — это ограничение yt-dlp.
