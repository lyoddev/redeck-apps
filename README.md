# ReDeck apps

Небольшие локальные программы для Linux, которые ставятся одной командой. Всё работает на твоём компьютере, без отправки данных в интернет (кроме скачивания моделей и библиотек при установке).

Проверено на Pop!_OS 22.04 (GNOME, X11).

## Программы

| ID | Что делает |
|---|---|
| `szhimatel` | Сжиматель видео на ffmpeg |
| `ocr-app` | «Картинки в текст»: распознавание текста с картинок |
| `qr-restore` | Восстановление битых и мутных QR-кодов |
| `napominalka` | Напоминания размяться, выпить воды, дать отдых глазам |
| `mediavault` | Личный офлайн-архив медиа на базе yt-dlp |
| `govori` | «Нажми и говори»: диктовка голосом по нажатию клавиши (нужен X11) |
| `slushai` | «Слушай и переводи»: расшифровка и перевод аудио и видео (использует библиотеки `govori`) |

## Установка

```bash
git clone https://github.com/ИМЯ_НА_GITHUB/redeck-apps.git
cd redeck-apps
bash install.sh список          # что есть
bash install.sh szhimatel       # поставить одну программу
```

Установщик сам доставит системные пакеты (спросит пароль), создаст отдельную папку с библиотеками, команду запуска и ярлык в меню приложений.

`slushai` нужно ставить после `govori`: он берёт у него общие библиотеки.

## Обновление и удаление

```bash
git pull
bash install.sh szhimatel       # переустановить с новой версией
bash install.sh удалить szhimatel
```

Настройки и данные программ (в `~/.config`, `~/.cache`) при удалении не трогаются.

## Как добавить свою программу

1. Создай папку `apps/<id>/` и положи туда код и иконку (`icon.svg`).
2. Добавь файл `app.conf`:

```
ID=my-app
NAME="Моя программа"
COMMENT="Что делает"
MAIN=my_app.py
APT="пакеты через пробел"
PIP="библиотеки через пробел"
ICON_FILE=icon.svg
CATEGORY="Utility;"
```

3. Если библиотек много, положи рядом `requirements.txt`.

Дополнительные поля: `PYMODE=system` (использовать системный Python), `SYSTEM_SITE=1` (venv с системными библиотеками), `RUN_MODULE=имя` (запуск пакета через `python -m`), `USE_ENV_OF=<id>` (взять библиотеки другой программы), `DESKTOP_ID`, `WMCLASS`, `NEEDS_X11=1`.

## Важно

- Установщик запускает команды с `sudo` только для установки системных пакетов. Посмотри `install.sh` перед запуском, это обычный текстовый скрипт.
- Большие модели (Whisper, языки перевода) в репозиторий не входят и скачиваются при первом запуске.
